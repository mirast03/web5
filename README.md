## Description

A small website with JavaScript tasks about the DOM and events.
The website has four pages and a navigation bar (navbar) on every page.
It uses only HTML, CSS and plain JavaScript (no libraries).

## Pages and tasks

| Page | File | Tasks |
|---|---|---|
| Part 1. Introduction | `index.html`, `part1.js` | Task 0 (first script), Task 1 (variables and operators) |
| Part 2. DOM | `dom.html`, `dom.js` | Task 2 (change text), Task 3 (change styles), Task 4 (add / remove list items) |
| Part 3. Events | `events.html`, `events.js` | Task 5 (mouse events), Task 6 (keyboard events), Task 7 (calculator) |
| Part 4. To-Do App | `todo.html`, `todo.js` | Task 8 (to-do list: add, complete, delete) |

All pages use the same styles from `style.css`.

## How to run

1. Download or clone the repository.
2. Open `index.html` in any browser (double click on the file).
3. Use the navbar at the top to move between the pages.
4. Open the browser console (F12 -> Console) to see the output of Task 0 and Task 1.

## How to use the To-Do app

1. Type a title and a description and press **Add Task**.
2. Press **Complete** to mark a task as done (the text is crossed out). Press **Undo** to return it back.
3. Press **Delete** to remove a task.

Tasks are stored in a JavaScript array, so they disappear after the page is reloaded.

## Publishing (GitHub Pages)

1. Upload all files to a GitHub repository (the files must be in the root of the repository).
2. Open **Settings -> Pages**.
3. In **Branch** choose `main` and the `/ (root)` folder, then press **Save**.
4. After a minute the website will be available at the link shown on that page.
